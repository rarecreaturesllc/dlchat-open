# Data inventory

Checked against the built app in T026 (2026-11-04), by reading code. Nothing is sent to the developer unless the person sends a bug report from Settings (see the Send Debug Logs row). No analytics, no accounts. Network use and the outside parties that see data are in the bold rows (public Nostr relays and Tor for online chat, the Mesh Map downloads, the Meshtastic radio).

"Sealed store" is one file, ChaCha-Poly sealed, excluded from backup, with its key in the Keychain (`Vault/Vault.swift`). "Wipe" means the hold-to-wipe button (Settings, Safety, lock screen, Tones, QR, Teleprompter), the duress PIN, and removing a group where the row says so. Wipe deletes the files and drops the key; it cannot rule out forensic recovery of traces from phone storage.
