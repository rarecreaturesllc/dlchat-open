DLChat needs no account and no sign-in. You can test everything without a radio.

To try it: open the app, make a group (the app generates the phrase), type a message on Send and choose Words, Sound or QR. On a second device with the same phrase, Receive opens the message. Chat works over the internet between two devices in the same group.

About radios: DLChat is not a radio and does not transmit on any band by itself. It can connect over Bluetooth to a Meshtastic radio the user already owns. Meshtastic radios use license-free ISM bands (in the US, 902 to 928 MHz under FCC Part 15), where encrypted data is allowed. The radio feature is off by default; turning it on shows a "Meshtastic radio rules" notice the user must accept, and DLChat will not send while the radio is in licensed mode. The user is responsible for following the rules where they are.

Bluetooth is used only for the Meshtastic radio. The microphone is used only to hear message sound played by another phone. The camera is used only to scan a QR code. Location is used only while the mesh map is open and stays on the phone.
